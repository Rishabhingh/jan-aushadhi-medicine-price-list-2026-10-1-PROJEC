# Jan Aushadhi Medicine Price List - 2026 Analysis

An Excel-based analysis of PMBJP (Pradhan Mantri Bhartiya Janaushadhi Pariyojana) medicines.

# What I Analyzed
- Total medicines listed in Oct 2026 list
- Generic vs Branded price comparison
- Max savings % (e.g. 70-90% cheaper)
- Category-wise distribution (Cardiac, Diabetic, Antibiotics etc.)
- Top 20 most affordable alternatives

# Tools Used
Excel - VLOOKUP, XLOOKUP, Pivot Table, Conditional Formatting, Charts

# Files
- Jan-Aushadhi-Price-List-Oct-2026.xlsx - Raw + Cleaned data
- Dashboard - Price comparison dashboard
- Screenshots/

# Key Insight
Jan Aushadhi medicines are 50-90% cheaper than branded, making healthcare affordable.
